Détail des unités

Clique un carré sur la carte ou une unité ci-dessous. Les icônes 🔥 marquent les combats actifs selon l’heure. Les croix blanches marquent les morts américains, les croix noires les morts allemands. Les points blancs/noirs marquent les récits localisés de soldats américains/allemands ; côté allemand, plusieurs points détaillent désormais compagnies, sections et mitrailleuses vers le village. Ils sont cliquables.
